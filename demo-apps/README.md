# Airwave Agents — Demo Apps

Try the demo with both halves of the product: the **broadcaster** app (Android)
and the **listener** web app (browser).

## 📻 Broadcaster (Android transmitter)

- **File:** [`broadcaster-demo-version.apk`](./broadcaster-demo-version.apk)
- **Install:** download the APK to an Android device and open it. You may need to
  allow "Install unknown apps" for your browser/file manager.
- On first open the library is auto-seeded with royalty-free demo songs, so you
  can go live right away.

## 🎧 Listener (web app)

- **URL:** https://airwave-agents.web.app — opens straight into the demo station,
  no station ID needed.

To open a specific broadcaster's station, add `?station=<uid>` — the broadcaster
app shows and shares this link from its home screen.
